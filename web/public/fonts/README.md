# Website typography

Fraunces, Space Grotesk, and Space Mono match the families used on https://ryoku.dev/.

Latin WOFF2 files are self-hosted so rendering and builds do not require a font service. The files were retrieved from the font URLs declared by the reference site's public stylesheet. Each family is distributed under the SIL Open Font License; the corresponding license files are included here.

Upstream sources:

- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/spacemono
